# Integração com Banco de Dados (TypeORM, Prisma, Mongoose)

O NestJS se integra facilmente a bancos de dados por meio de ORMs/ODMs como **TypeORM**, **Prisma** e **Mongoose**, facilitando as operações de persistência com injeção de dependência e organização modular.
